### 👨‍💻 About Me

I am a Software Developer based in **India**, driven by the curiosity to understand how systems function under the hood and passionate about building scalable, user-centric applications. My core expertise centers on **native Android development**, **cross-platform mobile apps with Flutter**, and **desktop utilities built with TypeScript and Electron**.

- **Currently Building:** [Nosved Player](https://github.com/DevSon1024/Nosved-Player) _(mpv-android based media player)_ & [PixChive](https://github.com/DevSon1024/PixChive) _(High-speed comic/manga reader)_
- **Deepening Knowledge In:** Jetpack Compose, Kotlin Multiplatform, Flutter/Dart, Coroutines, and System Architecture
- **Industry Background:** Former Developer Intern at **CareerSahi Edtech Pvt. Ltd.**
- **Engineering Philosophy:** Clean code, modular architecture, performance optimization, and intuitive UX
- 💬 **Ask Me About:** Kotlin, Jetpack Compose, Android SDK, Flutter, Dart, TypeScript, Electron, Media Decoders (mpv/FFmpeg/ExoPlayer)
